광고 픽셀 · 전환 태그

비워 두면 삽입되지 않습니다. ID + 체크한 이벤트만 이 글에 자동 삽입됩니다. 랜딩(조회)만이면 PageView만, 문의·신청 전환이면 Lead / 전환 라벨도 체크하세요.

Meta (페이스북·인스타) 입력됨

이벤트 관리자 → 데이터 소스 → 픽셀 ID.
ID만 넣으면 기본 PageView. 리드·구매 등 전환은 아래를 추가로 체크.

전송할 이벤트 (복수 선택)
TikTok 입력됨

TikTok Ads → 자산 → 이벤트 → 웹 픽셀 ID.
폼 제출·문의 랜딩이면 SubmitForm / Contact 를 함께 체크.

전송할 이벤트 (복수 선택)
Google (GA4 · Ads · GTM) 입력됨

· GA4 G-… = 분석
· Google Ads AW-… + 라벨 = 광고 전환 (리드/구매 라벨 분리 가능)
· GTM GTM-… = 태그 매니저 (GTM만 쓸 거면 나머지 비워도 됨)

GA4 추가 이벤트 (복수 선택 · page_view는 자동)
네이버 (분석 · 검색광고) 입력됨

wcs_add["wa"] 계정 ID 필수.
전환 유형을 고르면 wcs.cnv(유형, 값) 전환도 함께 전송. 비우면 페이지뷰(유입)만.

카카오 픽셀 입력됨

카카오 모먼트 → 픽셀 ID.
문의·신청 랜딩은 participation (참여/리드), 가입은 signUp.

전송할 이벤트 (복수 선택)

광고 전용

광고용 블로그 제작 사용방법

광고 랜딩 작성 · 목록 · 댓글 · 픽셀만 안내합니다. 아래 순서대로 따라 하시면 됩니다.

1. 작성 2. 목록·수정 3. 댓글 4. 픽셀 5. 팁
01

광고 블로그 작성

좌측 광고 → 광고 블로그 작성에서 새 랜딩을 만듭니다. 광고 글은 검색에 안 잡히도록 noindex 처리됩니다.

  1. 왼쪽 메뉴 광고 블로그 작성을 누릅니다.
  2. 제목과 본문(이미지·링크 카드 포함)을 작성합니다. 네이버 글을 붙여넣어도 됩니다.
  3. 하단에 픽셀 설정을 필요할 때만 입력합니다. (자세한 내용은 4번 참고)
  4. 저장하면 광고 블로그 목록으로 이동합니다. 공개 URL은 목록의 보기로 확인하세요.
링크 썸네일

본문에 URL만 넣으면 링크 카드가 만들어집니다. 저장 후 미리보기/공개 페이지에서 확인하세요.

02

광고 목록에서 수정·확인

작성한 랜딩은 광고 → 광고 블로그 목록에서 관리합니다.

  1. 제목·날짜·조회수를 한눈에 볼 수 있습니다.
  2. 수정으로 다시 편집하고, 보기로 실제 공개 화면을 엽니다.
  3. 새 랜딩이 필요하면 메뉴의 광고 블로그 작성으로 이동합니다.
03

광고 블로그 댓글

광고 랜딩 전용 댓글은 광고 → 광고 블로그 댓글에서만 관리합니다.

  1. 왼쪽에서 댓글을 달 광고 글을 선택합니다.
  2. 오른쪽에 기존 댓글·답글이 보입니다. 수정·삭제·답글을 관리할 수 있습니다.
  3. 아래 입력창에 내용을 쓰고 댓글 등록을 누르면 공개 페이지에도 바로 반영됩니다.
연출 팁

랜딩 신뢰도를 위해 초기에 자연스러운 질문·후기 형태의 댓글을 몇 개 미리 올려 두면 좋습니다.

04

매체별 광고 픽셀

작성 화면 하단 광고 픽셀 · 전환 태그에서 Meta / TikTok / Google / 네이버 / 카카오를 설정합니다.

  • ID만 넣으면 그 매체만 심김 — 비워 둔 매체는 스크립트가 아예 안 나갑니다. 여러 매체를 동시에 넣어도 서로 독립입니다.
  • 이벤트 복수 선택 — 체크한 이벤트가 페이지가 열릴 때 전부 한 번에 전송됩니다. (버튼 클릭 시점이 아님)
  • 권장 — 보통은 PageView만 켜 두세요. Lead·Purchase 등은 Ads에서 그 전환으로 최적화할 때만 추가하세요.
  • Purchase — 켜면 아래 금액 칸도 함께 넣는 것이 좋습니다.
  • 조회수 리포트 — 광고 → 광고 조회수 리포트에서 기간별 유입을 확인합니다.
05

자주 하는 실수 · 바로가기

광고 블로그 작업 시 참고하세요.

  • 이미지 깨짐 — 본문 이미지가 넓게 잘리면 공개 페이지에서 자동으로 맞춥니다. 그래도 이상하면 이미지를 다시 업로드해 보세요.
  • 링크 카드 썸네일 — 저장 후 공개 URL에서 확인하세요. 관리자에서 다시 저장하면 빈 카드도 복구됩니다.
  • SEO — 광고 글은 SEO 입력란이 숨겨지고 검색에 노출되지 않습니다. (의도된 동작)
